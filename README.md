# Rule-Based Student Study Assistant Agent

## Course
02AML204 - Introduction to Artificial Intelligence

## SLE-1

This project demonstrates a simple rule-based AI agent that provides study recommendations based on the user's study hours and mood.

## How It Works

The user enters:
- Number of study hours
- Mood: good, tired, or stressed

The agent applies predefined if-else rules and gives a suitable study recommendation.

## How to Run

1. Install Python 3.
2. Open Command Prompt in the project folder.
3. Run:

```text
python rule_based_agent.py
